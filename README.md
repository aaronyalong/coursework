# CNN and Transfer Learning on CIFAR-10

## Description
This project compares a baseline CNN, an improved CNN, and transfer learning using ResNet18 on the CIFAR-10 dataset.

## Models
- Baseline CNN
- Improved CNN
- ResNet18 (frozen)
- ResNet18 (fine-tuned)

## Results
Best validation accuracy: 95.44% (ResNet18 fine-tuned)

## How to run
Open the notebook in Google Colab and run all cells.
